### Spacing Principles
- **Internal spacing** (within components): --space-1 through --space-4
- **Component spacing** (between components): --space-4 through --space-8
- **Section spacing** (between layout sections): --space-12 through --space-24
- **Layout spacing** (page margins, max-width gutters): --space-16 through --space-32
- **Rule:** Never use arbitrary values. If the spacing isn't in the scale, the design decision is probably wrong.

## Motion & Animation

### Principles
- **Motion is purposeful:** Every animation should communicate something — state change, hierarchy, direction. Remove animation that is only decorative.
- **Respect user preferences:** All animation must respect `prefers-reduced-motion`. Provide static alternatives.
- **Speed communicates character:** [Fast/snappy = efficient, Slow/graceful = premium — define where this brand sits]

### Timing Tokens
```css
--duration-instant:  0ms;      /* state changes with no perceptible delay */
--duration-fast:     100ms;    /* micro-interactions, hover states */
--duration-normal:   200ms;    /* most UI transitions */
--duration-slow:     300ms;    /* larger element transitions, modals */
--duration-slower:   500ms;    /* page-level transitions, onboarding */
```

### Easing Tokens
```css
--ease-default:      cubic-bezier(0.2, 0, 0, 1);    /* most transitions */
--ease-in:           cubic-bezier(0.4, 0, 1, 1);    /* elements exiting */
--ease-out:          cubic-bezier(0, 0, 0.2, 1);    /* elements entering */
--ease-spring:       cubic-bezier(0.175, 0.885, 0.32, 1.275);  /* bouncy, use sparingly */
```

### Motion Rules
- Hover states: --duration-fast, --ease-default
- Modals/drawers entering: --duration-slow, --ease-out
- Modals/drawers exiting: --duration-normal, --ease-in
- Page transitions: --duration-slower, --ease-default
- Never animate: layout shifts that move content the user is reading, opacity-only animations on large surfaces (causes repaints)

## Accessibility Standards

**Target level:** WCAG 2.2 [AA / AAA]

### Non-negotiables
- **Color contrast:** 4.5:1 for normal text, 3:1 for large text (18px+ regular, 14px+ bold) and UI components
- **Focus visibility:** All interactive elements must have a visible focus indicator with 3:1 contrast against adjacent colors
- **Touch targets:** Minimum 24×24px (WCAG 2.5.8 AA); 44px recommended on touch surfaces
- **Keyboard navigation:** All interactions achievable without a pointer device
- **Screen reader support:** Semantic HTML first. ARIA only where HTML semantics are insufficient.
- **Motion:** All animations respect `prefers-reduced-motion: reduce`
- **Text resize:** UI must function at 200% browser zoom without horizontal scrolling

### Accessibility Checklist (per component)
- [ ] Color is never the sole means of conveying information
- [ ] Focus order is logical and follows visual order
- [ ] Interactive elements have visible focus states
- [ ] Images have descriptive alt text (or aria-hidden if decorative)
- [ ] Form inputs have associated labels
- [ ] Error messages are programmatically associated with their input
- [ ] Dynamic content changes are announced via aria-live regions
